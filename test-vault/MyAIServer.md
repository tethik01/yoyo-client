# MyAIServer

ASUS Ascent GX10 (NVIDIA GB10 Grace Blackwell), 128 GB unified memory at 273 GB/s.
Runs Ollama behind LiteLLM, exposed over Tailscale.

Two capabilities: `agent` (muse-glimmer, tool-reliable, ~12 tok/s) and `fast`
(qwen3.6, ~76 tok/s, must never be given tools).

The espresso machine in the office has nothing to do with this box.
